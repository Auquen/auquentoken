# AUQUEN (AQN)

A BEP-20 token for BNB Smart Chain with an automatic liquidity mechanism, a fixed supply, and a presale-friendly launch flow.

## Token Details

| Property | Value |
|---|---|
| Name | AUQUEN |
| Symbol | AQN |
| Standard | BEP-20 |
| Decimals | 18 |
| Total Supply | 1,000,000,000 AQN |
| Mint | None (supply is fixed at deployment) |
| Network | BNB Smart Chain |
| Solidity | ^0.8.20 |

## Features

- **Fixed supply.** The entire supply is minted once in the constructor. There is no mint function anywhere in the contract.
- **Auto-liquidity.** A fee is taken on buys and sells, collected in AQN. When the collected amount reaches the swap threshold, half is swapped to BNB and paired with the other half to add liquidity on PancakeSwap.
- **Locked liquidity.** LP tokens generated by the auto-liquidity mechanism are sent to the dead address (`0x000000000000000000000000000000000000dEaD`), so they are permanently locked.
- **Presale support.** Trading is closed for regular wallets until the owner calls `enableTrading()`. This is a one-way switch and cannot be reversed. Fee-exempt addresses (such as the owner and a presale contract) can transfer before trading opens.
- **Capped fees.** Buy and sell fees default to 3% and can never exceed 10%.
- **No restrictive controls.** There is no blacklist, no pause function, and no max-wallet or max-transaction limit.

## How Auto-Liquidity Works

1. On every buy or sell through the PancakeSwap pair, the fee is deducted and held by the contract.
2. When a sell occurs and the contract balance is at or above `swapThreshold` (default 0.05% of supply), the contract swaps half of the threshold amount for BNB.
3. The remaining half and the received BNB are added to the AQN/BNB pool.
4. The resulting LP tokens are sent to the dead address.

## Owner Functions

| Function | Description |
|---|---|
| `setFees(buyFee, sellFee)` | Update fees. Each is capped at 10%. |
| `setSwapThreshold(amount)` | Set the amount that triggers auto-liquidity (between 0.001% and 1% of supply). |
| `setSwapEnabled(bool)` | Enable or disable the auto-liquidity swap. |
| `setFeeExempt(account, bool)` | Exclude or include an address in fees and the pre-trading restriction. |
| `enableTrading()` | Open trading for everyone. Irreversible. |
| `manualSwapAndLiquify()` | Manually run auto-liquidity on the contract's AQN balance. |
| `renounceOwnership()` | Permanently give up ownership. |

## Launch Flow

1. Deploy the contract and verify it on BscScan.
2. Create the presale on your chosen launchpad and send it the presale and liquidity allocation.
3. Call `setFeeExempt(presaleContract, true)`. If your launchpad uses separate contracts for locking or claiming, exempt those as well.
4. Run the presale. Trading remains closed to regular wallets.
5. Finalize the presale so the launchpad adds and locks the initial liquidity.
6. Call `enableTrading()`.
7. Set the final fees, then optionally call `renounceOwnership()`.

> **Important:** Do not renounce ownership before calling `enableTrading()`, or trading will stay closed permanently.
